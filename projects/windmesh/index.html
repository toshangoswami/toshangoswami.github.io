WindMesh

2026 simulation Python · OpenCV · Roboflow · React

Problem

The wildfires in Los Angeles and Australia started this. How fast a fire spreads depends on wind speed, so we set out to measure the wind ourselves and predict the spread from it.

What I built

A homemade wind gauge, with computer vision measuring how fast it spins. Those relative wind speeds feed a Rothermel fire-spread model, which draws a map of how the fire will spread across a region over the next 20 minutes.

Media

Result

Placed 2nd of 50 participants at LexHack '26. Next: a physical mesh of wind-gauge nodes that feeds the simulation automatically.

Challenges

Three things were hard: getting the spread math right, getting computer vision to read the gauge accurately while it spun fast, and making the interface clear. We learned how to make computer vision hold up on fast-moving objects, and how to combine several variables in one predictive model.
