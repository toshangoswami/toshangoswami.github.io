Airframe AE

2026 damage detection Python · HTML · Arduino (C++)

Problem

Checking an airframe for cracks means grounding the plane for an inspection, which costs airlines time and money. I'm looking for a better way: sensors that monitor the hull continuously.

What I built

A simulation of an airliner fitted with acoustic emission sensor nodes. The nodes listen to the hull. The software isolates the frequencies a crack or dent gives off, then triangulates where it happened from how loud the event is at each node and how close the nodes are. The localization model runs in real time, in Python, on a 3D model of the plane. We started from an HTML model of the plane and its nodes, iterated against mock data until the predicted crack matched the real one, then added graphs of the sound data.

Media

Result

In simulation, the triangulation located cracks within 95% accuracy, built in 12 hours at CSI Hacks 2026. I'm now continuing it on my own as independent research: better hardware first, then real nodes under a laminated skin that can pick out crack frequencies from the background noise a plane makes every day.

Challenges

The hardware. We flew in from Boston on a time crunch and left key components behind, and the nearest Micro Center didn't have most of what we needed, so we couldn't build working hardware. I still learned how microphones and Arduinos interact, and how to program an Arduino in C++.
